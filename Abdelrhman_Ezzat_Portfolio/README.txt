# Abdelrhman Ezzat Portfolio

A simple responsive personal portfolio built with HTML, CSS, and JavaScript.

## Files
- `index.html` — portfolio content
- `style.css` — design and responsive layout
- `script.js` — current year in footer

## Before publishing
Open `index.html` and replace:
- `your.email@example.com` with your real email
- GitHub link with your GitHub profile
- LinkedIn link with your LinkedIn profile

Then open `index.html` in your browser to preview it.

## Publish with GitHub Pages
1. Create a GitHub repository named `yourusername.github.io`.
2. Upload the three website files.
3. In GitHub: Settings → Pages.
4. Select the main branch as the source.
5. Your portfolio will be available at `https://yourusername.github.io/`.
